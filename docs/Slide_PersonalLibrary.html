Suggerimenti Locali Personalizzati

Un algoritmo offline analizza le tue preferenze e suggerisce cosa leggere dopo
Come funziona l'algoritmo
1.Trova i libri letti con valutazione ≥ 4 stelle
2.Per ogni candidato (Da leggere / Wishlist) calcola uno score
3.+2 punti per stessa categoria · +2 per stesso autore
4.Mostra i top 3 con motivazione esplicita
✅ 100% locale — nessuna API esterna
Funziona anche senza connessione internet. I dati non lasciano mai il dispositivo.

Perché Context API + useReducer?
Redux avrebbe introdotto complessità non giustificata. Context + useReducer offre gli stessi vantaggi con molto meno boilerplate, ed è facilmente migrabile in futuro.
Perché AsyncStorage e non SQLite?
Sufficiente per la quantità di dati. Scrittura atomica JSON, nessuna dipendenza nativa, compatibilità perfetta con Expo Go SDK 54.
Grafici senza librerie esterne
BarChart e HBars implementati con pure View React Native: zero conflitti di versione, controllo totale dello stile.

Gestione Stato e Dati

Azioni del Reducer
ADD → Aggiunge elemento alla collezione
UPDATE → Aggiorna elemento per ID (immutabile)
DELETE → Rimuove + cascata automatica
SET_ALL → Ripristina intero stato
Sincronizzazione automatica stato
Dopo ogni ADD/UPDATE sulle sessioni, syncBookStatus() aggiorna automaticamente lo stato del libro:

• Prima sessione → Da leggere → In lettura
• Pagine complete → In lettura → Letto ✅
Cascata eliminazione
Eliminando un libro:
→ Sessioni associate eliminate
→ Note e recensioni eliminate
→ Riferimenti in tutte le liste rimossi

Eliminando un autore:
→ ID rimosso da tutti i libri (libri conservati)

Difficoltà e Soluzioni

🔴 Problema
Compatibilità Expo SDK 54
App Expo Go bloccata a SDK 54, conflitti con plugin expo-status-bar in app.json.
✅ Soluzione
Downgrade + app.json pulito
Installazione con --legacy-peer-deps. Rimosso il campo plugins da app.json.
🔴 Problema
Stale closure nel timer
Il countdown con setInterval + useState leggeva valori obsoleti del contatore.
✅ Soluzione
useRef per elapsed + updater funzionale
useRef per il contatore elapsed, aggiornamento con setSeconds(prev => prev - 1).
🔴 Problema
Navigazione cross-tab con parametri
Passare il bookId da Libreria a SessionForm nel Diario senza perdere il contesto.
✅ Soluzione
navigate con screen e params annidati
navigate('Diario', { screen: 'SessionForm', params: { bookId } })
